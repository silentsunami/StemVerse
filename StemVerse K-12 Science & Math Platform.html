Host on Render.com (`onrender.com`) Guide

Deploy this K-12 Science & Math portal as a free Render Static Site or Node Web Service in 2 minutes.

1. Push to GitHub / GitLab

Save this file as index.html alongside the render.yaml file below in a new Git repository.

2. Connect on Render.com

Log into dashboard.render.com, click New + → Static Site (or Blueprint) and pick your repository.

3. Live `.onrender.com` URL

Set Publish Directory to . (root). Render builds & serves your site globally on https://stemverse-k12.onrender.com!

render.yaml (Zero-Config Render Blueprint) 
services:
  - type: web
    name: stemverse-k12-portal
    runtime: static
    buildCommand: echo "Static K-12 Portal Ready"
    staticPublishPath: .
    routes:
      - type: rewrite
        source: /*
        destination: /index.html
Optional: server.js (If hosting as a Render Node.js Web Service) 
const express = require('express');
const path = require('path');
const app = express();
const PORT = process.env.PORT || 3000;

app.use(express.static(__dirname));
app.get('*', (req, res) => res.sendFile(path.join(__dirname, 'index.html')));

app.listen(PORT, () => console.log(`StemVerse live on port ${PORT}`));
